# Unit Distance Graph Viewer
Viewer for Unit Graphs constructed from a Grid
![Screenshot of the interface](images/ui.png)

This project allows to visualize and explore unit graphs.

![Visualization of the Dodeka plane with 5 levels depth](images/dodeka-plane.png)

## Prerequisites
* SDL3
* ImGui
* Meson

## Build
```
meson build
cd build
meson compile
./unitdistancegraphviewer
```
